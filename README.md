A computer networking assignment created in **Cisco Packet Tracer**.

## How to open

1. Install Cisco Packet Tracer.
2. Download the `.pkt` file from this repository.
3. Open Cisco Packet Tracer and select **File → Open**.
4. Choose `Nihal_Hameed_Assignment1.pkt` to inspect the network topology and its saved configuration.
